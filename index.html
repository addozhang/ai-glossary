关于与更新

内容、协议与维护方式。

内容：全部词条原创撰写，唯一内容源是仓库里的 content/glossary.md。参考项目仅提供链接，未复制任何未授权内容。

分类与标签：12 个分类对应知识层级，8 个标签是跨分类的横向维度（核心 / 易混淆 / 工程 / 成本 / 新词 / 营销 / 有争议 / 安全）。两者都是 data/taxonomy.json 里的受控词表，由 CI 校验，不允许随意新增。

更新：改 content/glossary.md 后运行 npm run check（编译 + 校验），push 后 GitHub Pages 自动生效。本地写作可用 npm run watch 自动编译。在线查看内容源 · 在 GitHub 上编辑

隐私：纯静态、零依赖、无 CDN、无 Cookie、无追踪脚本，可离线打开。主题偏好仅存于本机 localStorage。

协议：正文采用 CC BY 4.0，转载请署名。站点代码采用 MIT。
